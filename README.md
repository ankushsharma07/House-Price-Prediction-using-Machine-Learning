## 📌 Project Overview

This project predicts **house prices** using **Linear Regression**.

The project demonstrates the complete Machine Learning workflow, including:

- Data Loading
- Exploratory Data Analysis (EDA)
- Data Cleaning
- Feature Selection
- Train-Test Split
- Model Training
- Model Evaluation
- House Price Prediction

---

## 🚀 Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-Learn
- Jupyter Notebook

```bash

```bash

python main.py
